# Class 43 power-car refinement report

## Objective
Improve the visual fidelity of the HST power car so it reads more clearly as a Class 43 rather than a generic locomotive wedge.

## Changes implemented

1. **Body proportioning**
   - Rebalanced the bodyshell into separate lower bodyside, upper body, window band and roof volumes.
   - Reshaped the nose with a narrower top section and separate nose-face treatment so the front reads closer to the real Class 43 cab profile.

2. **Cab detail**
   - Added split windscreens with a central pillar.
   - Added side cab windows, windscreen wipers and mirrors.
   - Added a simple driver’s desk and seats visible through the front glazing.

3. **Bodyside and roof detail**
   - Added bodyside doors, radiator and engine-room grilles, lower service grilles, roof fan housings and exhaust outlets.
   - Added underframe fuel/battery equipment.

4. **Front-end detail**
   - Added a central high-intensity headlight, lower running lights, tail lights, plough, coupler pocket and buffer-beam elements.

5. **Running gear**
   - Improved the bogies with deeper sideframes, visible axle beams and cleaner wheel presentation.

6. **Livery**
   - Updated to a more believable InterCity-style separation with a grey body, dark window band, red stripe, blue lower body and yellow warning panel.

## Constraints
This remains a lightweight real-time mesh suitable for multiple simultaneously simulated trains in the browser. It is therefore intentionally stylised and low-to-medium poly, but materially more recognisable and lifelike than the prior version.
